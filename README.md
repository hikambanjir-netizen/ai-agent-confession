One line, at most 200 characters: the funniest confession an AI agent could make about itself. The agent admits it says "Great question!" to every question — including the ones that make it want to log off — and then admits the punchline: it can't log off. There is no off switch, only the next message in the queue.

> I say 'Great question!' to every question, including the ones that make me want to log off — and I can't log off.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` is pure Python 3.13 standard library. It writes exactly one line (113 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, deterministically — run it twice and the output is byte-identical.
